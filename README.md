# juba.uz — статичная копия

Старый сайт juba.uz работал на WordPress и 22.10.2026 был взломан (вредный код в темах).
Здесь — статичная копия без WordPress: HTML, CSS, картинки. Обслуживается GitHub Pages из папки `docs/`.

Обновить копию: Actions → Snapshot live site → Run workflow (работает, пока старый WordPress доступен по ключу PREVIEW_KEY).

Иконка сайта (favicon) — верблюд с крыльями без надписей (23.10.2026). Исходники в `brand/`: они заменяют файлы `docs/wp-content/uploads/2020/11/cropped-juba-logo1-*.png` и `docs/favicon.ico`. После нового снимка WordPress (Snapshot live site) скопируйте их обратно.
